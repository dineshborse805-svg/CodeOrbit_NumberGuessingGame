 # CodeOrbit Tech - Number Guessing Game

## Task 3: Number Guessing Game

A simple command-line Number Guessing Game built using Python as part of the CodeOrbit Tech Python Programming Internship.

## Features

- Generates a random number between 1 and 100
- Allows the user to guess the number
- Gives "Too high" and "Too low" hints
- Tracks the number of attempts
- Allows multiple rounds
- Handles invalid input
- Simple command-line interface

## Requirements

- Python 3.x

## How to Run

Open the terminal in the project folder and run:

```bash
python number_guessing_game.py
